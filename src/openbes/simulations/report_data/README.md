# Report data notes

## per_FEC_coefficients

This is a table of by-country coefficients for modelling the conversion of Primary Energy Consumption to Final Energy Consumption.
The columns give coefficients for PEC, PEC for non-renewable sources, and kilograms of CO2 required for each kWh of FEC.

Data are calculated by CIEMAT using Cumulative Energy Demand method for PEC and IPCC method for kg CO2.
